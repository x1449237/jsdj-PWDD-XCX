## 五、Nginx 配置

### 5.1 后端 API 配置
创建 `/etc/nginx/conf.d/game-platform.conf`：
```nginx
# 后端 API
server {
    listen 80;
    server_name api.yourdomain.com;
    root /var/www/project/php/public;
    index index.php;

    # 日志
    access_log /var/log/nginx/api_access.log;
    error_log /var/log/nginx/api_error.log;

    # 上传限制
    client_max_body_size 50M;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    location / {
        if (!-e $request_filename) {
            rewrite ^(.*)$ /index.php?s=$1 last;
        }
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.0-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_param PHP_VALUE "open_basedir=/var/www/project/php/:/tmp/";
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }

    # 禁止访问敏感文件
    location ~ /\. {
        deny all;
    }
    location ~ /(runtime|vendor)/ {
        deny all;
    }
}

# WebSocket 代理
server {
    listen 80;
    server_name ws.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:2345;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 86400s;
        proxy_send_timeout 86400s;
    }
}

# Web 管理后台
server {
    listen 80;
    server_name admin.yourdomain.com;
    root /var/www/project/admin-web/dist;
    index index.html;

    access_log /var/log/nginx/admin_access.log;
    error_log /var/log/nginx/admin_error.log;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 5.2 启动 Nginx
```bash
nginx -t
systemctl enable nginx
systemctl restart nginx
```

### 5.3 宝塔面板 HTTPS 部署（推荐方案）

宝塔面板使用 Nginx 终结 TLS，反向代理到 Go 后端 HTTP 端口，**无需启用 Go 自带的 TLS**（`config.yaml` 中 `tls_enable` 保持 `false`）。三个域名（API / Web 后台 / WebSocket）分别在宝塔建站并配置 SSL。

#### 步骤一：在宝塔创建三个站点
1. 登录宝塔面板 → 【网站】→【添加站点】
2. 依次创建三个站点（域名需已解析到本服务器）：
   - `api.yourdomain.com`（后端 API）
   - `admin.yourdomain.com`（Web 管理后台）
   - `ws.yourdomain.com`（WebSocket，可选独立站点或与 API 合并）
3. 后台站点把根目录设为 `admin-web` 构建产物路径，如 `/www/wwwroot/admin-web/dist`，运行目录选 `dist`。
4. 在【文件】中把构建好的 `admin-web/dist` 上传到对应目录（或用宝塔【终端】执行 `npm run build` 后 `mv dist/* /www/wwwroot/admin-web/dist/`）。

#### 步骤二：申请并部署 SSL 证书
对每个站点分别操作：
1. 进入【网站】→ 点对应站点【设置】→【SSL】
2. 推荐选【Let's Encrypt】→ 勾选域名 →【申请】（免费、90 天自动续签）
   - 若用自有证书：选【其他证书】→ 粘贴 `.key` 私钥与 `.pem` 证书 →【保存】
3. 申请成功后开启右上角【强制HTTPS】开关（自动 80 跳转 443）

> 申请 Let's Encrypt 前请确认：域名已解析、80 端口可访问、站点已正确绑定域名、未开启 CDN 或已关闭源站暴露。

#### 步骤三：配置反向代理（关键）
Go 后端保持监听 HTTP（默认 8080），WebSocket 监听 2345。在每个站点的【设置】→【配置文件】中按下方模板修改。

**① api.yourdomain.com —— 后端 API 反代**
在 `server` 块（443）内添加：
```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;   # 透传 https 标识
    client_max_body_size 50M;                      # 语音/截图上传
    proxy_read_timeout 300s;
}
```

**② admin.yourdomain.com —— Web 后台静态 + API 反代**
```nginx
location / {
    try_files $uri $uri/ /index.html;
}

location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

**③ ws.yourdomain.com —— WebSocket（必须 wss://，需 Upgrade 头）**
```nginx
location / {
    proxy_pass http://127.0.0.1:2345;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 86400s;
    proxy_send_timeout 86400s;
}
```
修改后保存，宝塔会自动 `nginx -t` 校验，无误则自动 reload。

#### 步骤四：放开端口
宝塔【安全】→ 放行 `8080`（后端）、`2345`（WebSocket）。生产建议仅放行 `80/443` 对外，`8080/2345` 限制为 `127.0.0.1` 访问（在站点反代里用 `127.0.0.1:8080` 即可，无需对公网开放后端端口）。

#### 步骤五：前端配置适配
- **小程序** `WX-xcx/utils/request.js`：`baseURL` 改为 `https://api.yourdomain.com/api/v1`
- **Web 后台** `admin-web/src/utils/request.js`：`baseURL` 保持 `/api/v1/admin`（相对路径，由 nginx 反代）
- **小程序 WebSocket**：连接地址改为 `wss://ws.yourdomain.com/ws`
- **微信小程序后台**：【开发管理】→【开发设置】→【服务器域名】添加 `https://api.yourdomain.com`（request/uploadFile/downloadFile）和 `wss://ws.yourdomain.com`（socket）

#### 步骤六：Go 后端进程守护（宝塔 Supervisor）
1. 宝塔【软件商店】安装【Python项目管理器】或【Supervisor管理器】
2. 添加守护进程：
   - 名称：`game-backend`
   - 启动命令：`/www/wwwroot/go-backend/jisan-e-sports-platform`（编译后的二进制，见教程第三章）
   - 运行目录：`/www/wwwroot/go-backend`
   - 启动用户：`root`
3. 启动并设为开机自启。日志在宝塔面板直接查看。

#### 常见问题
- **证书续签失败**：Let's Encrypt 续签需 80 端口可访问，确认未把 80 强制跳转 443 的规则写到续签验证目录之外，或临时关闭强制 HTTPS。
- **wss 连接失败**：检查 nginx 是否漏配 `Upgrade`/`Connection` 头；小程序后台 socket 域名是否已配置。
- **上传 502/413**：`client_max_body_size` 调大至 `50M`，确认后端进程存活（宝塔 Supervisor 查看状态）。
- **获取不到真实 IP**：后端需信任 `X-Forwarded-For`，nginx 已设置 `X-Real-IP`，Go 侧可用 `gin` 的 `trustedProxies` 配置 `127.0.0.1`。

## 八、SSL 证书配置（HTTPS）—— 必做

> 微信小程序强制要求 request/uploadFile/downloadFile/socket 域名为 https/wss，不配置 HTTPS 小程序无法提交审核、无法上线，支付回调、实名认证、IM 语音消息均不可用。本节为必做步骤。

### 8.1 架构说明

采用 **Nginx 终结 TLS + 反代后端 HTTP** 架构：
- 客户端 → `https://api.yourdomain.com` → Nginx(443) → Go 后端(8080, HTTP)
- WebSocket → `wss://ws.yourdomain.com` → Nginx(443) → Go WS(2345, HTTP)
- Web 后台 → `https://admin.yourdomain.com` → Nginx(443) → 静态文件 + 反代 API

因此 **Go 后端 `config.yaml` 中 `tls_enable` 保持 `false`**，HTTPS 由 Nginx 处理。后端已配置 `SetTrustedProxies(127.0.0.1)` 以获取真实客户端 IP。

### 8.2 后端配置适配（4.4 节补充）

`go-backend/internal/config/config.yaml` 保持 HTTP 监听：
```yaml
app:
  port: 8080
  tls_enable: false      # 宝塔/nginx 反代场景保持 false
  tls_cert: ""
  tls_key: ""
  tls_port: 8443
```

> 若后端直接对外暴露（不经 nginx），则设 `tls_enable: true` 并填证书路径，详见 [config.go](../go-backend/internal/config/config.go) 的 `AppConfig`。

### 8.3 方案一：宝塔面板申请 Let's Encrypt（推荐）

1. 登录宝塔面板 → 【网站】→ 分别为 `api/admin/ws` 三个站点点【设置】→【SSL】
2. 选【Let's Encrypt】→ 勾选域名 →【申请】（免费，90 天自动续签）
3. 申请成功后开启右上角【强制HTTPS】（自动 80 跳转 443）

> 申请前确认：域名已解析到本服务器、80 端口可访问、未开启 CDN 源站暴露。

### 8.4 方案二：Certbot 命令行申请

```bash
# CentOS
yum install -y certbot python3-certbot-nginx

# Ubuntu
apt install -y certbot python3-certbot-nginx

# 申请并自动配置 Nginx
certbot --nginx -d api.yourdomain.com -d ws.yourdomain.com -d admin.yourdomain.com
```

### 8.5 方案三：自有证书

在宝塔站点【SSL】→【其他证书】粘贴 `.key` 私钥与 `.pem` 证书 →【保存】；或放至 `/etc/nginx/ssl/`：
```bash
mkdir -p /etc/nginx/ssl
# 上传 server.crt / server.key
chmod 600 /etc/nginx/ssl/server.key
```

### 8.6 Nginx 反向代理配置（关键）

在各站点【配置文件】的 443 `server` 块内添加反代规则：

**① api.yourdomain.com —— 后端 API**
```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;   # 透传 https 标识
    client_max_body_size 50M;                      # 语音/截图/证件上传
    proxy_read_timeout 300s;
}
```

**② admin.yourdomain.com —— Web 后台静态 + API 反代**
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

**③ ws.yourdomain.com —— WebSocket（必须 wss，需 Upgrade 头）**
```nginx
location / {
    proxy_pass http://127.0.0.1:2345;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 86400s;
    proxy_send_timeout 86400s;
}
```

保存后宝塔自动 `nginx -t` 校验并 reload；命令行用 `nginx -t && nginx -s reload`。

### 8.7 强制 HTTPS 跳转

宝塔开启【强制HTTPS】即可。命令行在 80 端口 `server` 块加：
```nginx
server {
    listen 80;
    server_name api.yourdomain.com admin.yourdomain.com ws.yourdomain.com;
    return 301 https://$host$request_uri;
}
```

### 8.8 证书自动续签

- **宝塔**：Let's Encrypt 自动续签，留意面板【计划任务】中的续签任务日志
- **Certbot**：自动添加 systemd timer，验证续签 `certbot renew --dry-run`

续签失败告警脚本（加入宝塔【计划任务】，每天执行）：
```bash
#!/bin/bash
# 证书过期前 15 天告警
DAYS=15
certbot certificates 2>/dev/null | grep "Expiry Date" | while read line; do
  expiry=$(echo $line | grep -oE '[A-Z][a-z]+ [0-9]+ [0-9:]+ [0-9]+ UTC')
  remain=$(( ($(date -d "$expiry" +%s) - $(date +%s)) / 86400 ))
  if [ "$remain" -lt "$DAYS" ]; then
    echo "证书将在 ${remain} 天后过期：$line" >> /var/log/cert-expire.log
  fi
done
```

### 8.9 验证 HTTPS 生效

```bash
# 1. 检查证书
echo | openssl s_client -connect api.yourdomain.com:443 -servername api.yourdomain.com 2>/dev/null | openssl x509 -noout -dates

# 2. 测试 API
curl -I https://api.yourdomain.com/api/v1/health

# 3. 测试 WebSocket (wss)
# 浏览器控制台执行：new WebSocket('wss://ws.yourdomain.com/ws')

# 4. 测试 HTTP 自动跳转
curl -I http://api.yourdomain.com   # 应返回 301 到 https
```

### 8.10 常见问题

| 问题 | 解决方案 |
|------|---------|
| 证书续签失败 | Let's Encrypt 续签需 80 端口可访问，临时关闭强制 HTTPS 跳转或确保 `.well-known/acme-challenge/` 不被反代 |
| wss 连接失败 | 检查 nginx 是否漏配 `Upgrade`/`Connection` 头；小程序后台 socket 域名是否已配置 |
| 上传 502/413 | `client_max_body_size` 调大至 `50M`，确认后端进程存活 |
| 后端拿不到真实 IP | 确认 nginx 配了 `X-Real-IP`，后端已 `SetTrustedProxies(127.0.0.1)` |
| 混合内容拦截 | 确保小程序/Web 所有资源都走 https，无 http 引用 |
| 私钥泄露风险 | `.key` 文件权限 `chmod 600`，切勿提交 git |

```bash
#!/bin/bash
```

## 十三、微信小程序发布

### 13.1 配置合法域名（必须 HTTPS）

在微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名中配置（**必须是 https/wss，http 会被微信拒绝**）：

| 域名类型 | 配置值 | 用途 |
|---------|--------|------|
| request 合法域名 | `https://api.yourdomain.com` | 全部 HTTP 接口（含扩展模块 100+ 接口） |
| socket 合法域名 | `wss://ws.yourdomain.com` | IM 文字消息、60秒语音消息收发 |
| uploadFile 合法域名 | `https://api.yourdomain.com` | 头像、证件照、订单截图、语音文件上传 |
| downloadFile 合法域名 | `https://api.yourdomain.com` | 图片、语音、PDF 文件下载 |

> 配置前需完成第八章 HTTPS 部署，证书必须有效，否则微信校验不通过。

### 13.2 配置后端地址

编辑 `WX-xcx/utils/request.js`，将 `baseURL` 改为真实 https 域名：
```javascript
const BASE_URL = 'https://api.yourdomain.com/api/v1';
```

编辑 `WX-xcx/utils/websocket.js`，WebSocket 改为 wss：
```javascript
const WS_URL = 'wss://ws.yourdomain.com';
```

> 开发环境可在微信开发者工具勾选【不校验合法域名】，但真机预览/体验版/正式版必须用 https/wss 且域名已在后台配置。

### 13.3 上传代码
在微信开发者工具中点击 "上传"，填写版本号和备注。

### 13.4 提交审核
在微信公众平台提交审核，等待通过后发布。

## 十五、故障排查

### 常见问题

**Q: 502 Bad Gateway？**
检查 PHP-FPM 是否运行：`systemctl status php8.0-fpm`

**Q: WebSocket 连接不上？**
检查 Workerman 进程：`supervisorctl status game-platform-worker`

**Q: 小程序请求超时？**
1. 检查域名是否配置正确
2. 检查 SSL 证书是否有效
3. 检查防火墙是否开放 443 端口

**Q: 数据库连接慢？**
1. 检查慢查询日志
2. 优化索引
3. 考虑读写分离

**Q: 提现或支付异常？**
1. 检查 Redis 是否运行
2. 检查分布式锁是否正常释放
3. 查看后台日志定位问题
